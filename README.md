# ActivLab Pharma Doctor Catalog

Single-page catalog of ActivLab Pharma / Aqua Care supplements for physicians (distributed by Unique Treatment).

- `index.html` — the whole app (images embedded, no build step)
- `netlify.toml` — Netlify settings (publish root, no-index headers)

## Update
Replace `index.html` with the new version, commit and push. Netlify redeploys automatically.
